# APMLogViewer 插件开发指南

**适用版本**：宿主 APMLogViewer 0.1.0 ／ 插件接口 `API_VERSION = 1` ／ ArduCopter DataFlash 日志（4.6.x / 4.7.x）

这份文档是**唯一需要读的东西**：照着写、照着贴，就能做出一个能加载、能跑、能看到效果的插件。
文末附 API 速查表、拒绝条件清单、常见问题与一份可以直接拷走的完整示例。

---

## 0. 五分钟上手（最短路径）

1. **找到插件目录**：`%LOCALAPPDATA%\APMLogViewer\plugins`
   （资源管理器地址栏直接粘 `%LOCALAPPDATA%\APMLogViewer\plugins` 回车）。目录不存在的话，打开一次主窗工具栏的「插件」页就会自动建出来。
2. **新建文件** `hello.py`，内容照抄：

```python
PLUGIN_NAME = "你好插件"
__version__ = "1.0"

from PySide6 import QtWidgets


def register(ctx):
    page = QtWidgets.QWidget()
    lay = QtWidgets.QVBoxLayout(page)
    lay.addWidget(QtWidgets.QLabel(f"宿主 {ctx.host_version}，接口 v{ctx.api_version}"))
    ctx.register_tab("Hello", page)
    ctx.log.info("hello 插件已注册")
```

3. **回主窗，点工具栏「插件」→「重新扫描并重载」**。
4. **看效果**：主窗标签栏多出「Hello」一页；插件页表格里出现 `你好插件 1.0 已启用 标签页`。
5. **出错怎么办**：插件页选中该行 →「查看错误…」，里面是完整 traceback；状态栏也会留一句。

> 想让 `ctx.log` 的输出看得见，用源码方式启动：`python run_gui.py`（绿色包是窗口程序，没有控制台，错误请看插件页）。

三个最容易踩的点，先说在前面：

- 文件里**必须**有 `def register(ctx):`，没有就是「加载失败：插件缺少 register(ctx) 入口」。
- 文件名就是插件 id（`hello.py` → id `hello`）。以 `_` 或 `.` 开头的文件/目录**会被跳过**。
- `register()` 里抛异常 = 这个插件整体「加载失败」，它已注册的东西会全部撤掉（其它插件不受影响）。

## 1. 插件放在哪、怎么被加载

### 1.1 扫描哪些目录

| 优先级 | 来源 | 说明 |
| --- | --- | --- |
| 1 | `%LOCALAPPDATA%\APMLogViewer\plugins` | 默认目录，启动时不存在会自动创建 |
| 2 | 设置项 `plugin_dirs` | JSON 数组字符串，插件页「添加目录…」自动写入 |
| 3 | 环境变量 `APMLOG_PLUGIN_DIRS` | 多个目录用 `;` 分隔（`os.pathsep`） |

- 三处**按顺序**扫描，同一个目录出现多次只扫一次（按解析后的绝对路径去重）。
- 目录不存在**不算错**：跳过即可，主程序照常启动。
- 想临时加一个目录（比如同事发来一个 zip 解压到 D 盘）：插件页「添加目录…」选目录即可，会写进设置、下次启动仍然有效；「移除」只移除追加的目录，默认目录不会被移除。

### 1.2 什么会被当成插件，什么会被跳过

| 扫描到的对象 | 处理 |
| --- | --- |
| `xxx.py` 文件 | 当作插件，id = `xxx` |
| 目录，里面有 `__init__.py` | 当作包插件，id = 目录名；包内可写 `import .helper` 之类的相对导入 |
| 目录，里面只有 `plugin.py` | 当作单模块插件，id = 目录名（`plugin.py` 里**不能**用相对导入） |
| 以 `_` 开头的文件/目录（`_scratch.py`、`_old/`） | **跳过**（放草稿、备份用） |
| 以 `.` 开头的文件/目录（`.hidden.py`） | **跳过** |
| 其它扩展名（`README.md`、`notes.txt`、`data.csv`） | 忽略 |
| 目录，但既没有 `__init__.py` 也没有 `plugin.py` | 忽略（放数据文件可以） |

id 的字符只允许 `[0-9A-Za-z_.-]`，其它字符会被替换成 `_`。id 会出现在：
插件页的名称列、错误信息、`plugin:<id>:<主题>` 这样的设置值里。

```
%LOCALAPPDATA%\APMLogViewer\plugins\
├── hello.py                 ← 插件 id: hello
├── my_tools\                ← 插件 id: my_tools（包）
│   ├── __init__.py          ←   必须有 register(ctx)
│   ├── helpers.py           ←   可以 from . import helpers
│   └── assets\map.json
├── _draft.py                ← 跳过
└── README.md                ← 忽略
```

### 1.3 最小结构

一个插件**最少**只要这些：

```python
PLUGIN_NAME = "我的插件"      # 可选，插件页显示名；不写就用 id
__version__ = "0.1"          # 可选，插件页版本列；不写显示 "—"

def register(ctx):           # 必须
    ...
```

`register(ctx)` 在插件被加载时**调用一次**，你在这里做所有注册（挂载点、信号连接）。
函数返回后宿主认为加载完成；此后你只能通过信号和已注册的回调被调用。

> 建议：`register` 里只做「注册/连接」，不要做耗时计算（解析大文件、跑模型）。
> 需要预热就放到 `ctx.signals.log_loaded` 的回调里，或者起线程。

### 1.4 重载、启停、看错误

主窗工具栏「插件」页：

| 操作 | 效果 |
| --- | --- |
| 重新扫描并重载 | 清空所有插件及其注册内容，按当前目录重新加载（改完代码点这个） |
| 停用 | 立刻摘掉该插件注册的**全部**内容（预设消失、标签页移除、地图图层清空、告警规则不再参与、正在用的主题回退默认） |
| 启用 | 按原路径重新加载这一个插件 |
| 查看错误… | 显示最近一次错误的完整 traceback（双击行也可以） |
| 添加目录… / 移除 | 维护 `plugin_dirs`（只影响追加目录） |

「提供的扩展」列会列出它注册了什么：`告警规则 / 合成通道 / 预设视图 / 曲线工具 / 地图图层 / 标签页 / 导出器 / 主题`。

### 1.5 源码运行 vs 免安装绿色包

| 项目 | 源码运行（`python run_gui.py`） | 免安装版（`dist/APMLogViewer/APMLogViewer.exe`） |
| --- | --- | --- |
| 插件目录 | 同上，完全一样 | 同上，完全一样 |
| 加/改插件 | 拷文件 + 重载，**不用重启宿主** | 拷文件 + 重载，**不用重打包** |
| 能 import 什么库 | `.venv` 里装的全部 | 只有打包进去的那些（见下表） |
| `ctx.log` / `print` 输出 | 控制台可见 | 没有控制台；错误看插件页「查看错误…」 |
| 新增第三方库依赖 | `pip install` 即可 | 装进构建用的 venv → `python packaging/build.py build` 重新打包 |

**当前绿色包里已包含的库**（可以直接 import）：

`numpy`、`PySide6`（QtCore / QtGui / QtWidgets / QtNetwork / QtOpenGL 等）、
`pyqtgraph`、`pymavlink`、`pyserial`（import 名 `serial`）、`PyYAML`（`yaml`）、标准库。

**默认不在包里**：`scipy`、`pandas`、`matplotlib`、`PIL`、`numba`、`sklearn`、`h5py`、`statsmodels`、`openpyxl`、`duckdb`。
打包配置里已经预留了这些名字（`packaging/apmlogviewer.spec` 的 `OPTIONAL_PLUGIN_MODULES`）：
在构建机 venv 里 `pip install scipy` 之后重新 build，就会自动带上；没装就安静跳过。`duckdb` 是刻意排除的（+30 MB 且宿主自己不用）。

> 判断当前是不是绿色包：`getattr(sys, "frozen", False)`。

## 2. 生命周期

```
扫描目录
   │
   ├─ 导入模块（import 阶段异常 → 该插件「加载失败」）
   ├─ 读 PLUGIN_NAME / __version__
   ├─ 调 register(ctx)      ← 你在这里注册挂载点、连信号
   │     └─ 期间任何异常 → 撤掉已注册内容，插件「加载失败」
   └─ 状态：已启用
        │
        ├─ 宿主事件 → 你的回调（都在隔离沙箱里跑，异常不外溢）
        ├─ 用户操作 → 你的导出器 / 曲线工具 / 主题应用
        │
        ├─ 累计 5 次异常 → 自动「已停用」并摘掉全部内容
        └─ 用户点「停用」 → 同上（原因记为"手动停用"）
```

**register 里应该做的**：`ctx.register_*`、`ctx.signals.*.connect`、准备纯数据。
**register 里不要做的**：弹窗、长时间计算、`QApplication.quit()`、改宿主设置、假设日志已打开
（加载插件时可能一份日志都没打开，`ctx.store.available` 是 `False`）。

## 3. 上下文对象 `ctx`

`register(ctx)` 收到的 `ctx` 是 `PluginContext`：

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `ctx.plugin_id` | `str` | 本插件 id |
| `ctx.api_version` | `int` | 接口版本，当前 `1`。大改会 +1，可在 register 里判断并拒绝运行 |
| `ctx.host_version` | `str` | 例如 `"APMLogViewer 0.1.0"` |
| `ctx.store` | `StoreView` | **只读**日志数据（每次访问都拿当前日志的视图） |
| `ctx.control` | `ControlPort` | 主动控制宿主（打开日志、定位、切主题…） |
| `ctx.signals` | `PluginSignals` | 宿主 → 插件的 Qt 信号（全局一份，所有插件共享） |
| `ctx.settings` | `SettingsView` | **只读**宿主设置 |
| `ctx.log` | `logging.Logger` | 名字是 `apmlog.plugin.<你的 id>` |

### 3.1 `ctx.store` —— 只读数据接口

`ctx.store` 是**快照式只读视图**：方法返回的 `dict` 是新字典，numpy 是**拷贝**且 `writeable=False`；
实例内部不持有 `LogStore`，对 `ctx.store` 赋值会直接抛 `AttributeError`。
换句话说：**你可以随便读，改不动宿主任何东西**。

#### 方法一览

| 方法 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `available` | —（属性） | `bool` | 有没有打开日志。**先判它**再调其它方法 |
| `name()` | — | `str` | 日志文件名（不含目录） |
| `path()` | — | `str` | 日志绝对路径 |
| `meta()` | — | `dict` | 缓存索引的深拷贝（JSON 化：元组变列表、ndarray 变 list） |
| `stats()` | — | `dict` | `LogStats` 字段：`path log_id size_bytes duration t_start t_end takeoff_t land_t firmware board frame_type git n_messages n_types n_params n_events mode_seq max_alt distance max_speed pos_source pos_kind crashes segments warnings` |
| `types()` | — | `list[str]` | 报文类型名，已排序（如 `["ATT","BAT","VIBE"]`） |
| `has_type(t)` | `t: str` | `bool` | 有没有这个报文类型 |
| `channels(prefix=None)` | `prefix: str\|None` | `list[dict]` | 通道清单，见下表；`prefix` 按类型名前缀过滤（不区分大小写） |
| `keys(prefix=None)` | 同上 | `list[str]` | 只要通道键，如 `["VIBE#0.VibeX", ...]` |
| `channel_range(key)` | `key: str` | `dict` | 精确量程/统计：`min max mean std rms p05 p50 p95 n unit` |
| `series(key, t0=None, t1=None, max_points=None, drop_nan=False)` | 见下 | `SeriesData` | 取一条时序 |
| `series_dict(keys, t0=None, t1=None, max_points=None)` | `keys: Sequence[str]` | `dict[str, SeriesData]` | 批量取；取不到的键**不出现在结果里**（不抛错） |
| `envelope(key, t0=None, t1=None, buckets=2000)` | 见下 | `EnvelopeData` | 分桶包络（min/max/mean/count） |
| `events(kinds=None, severity_min=None, t0=None, t1=None)` | 见下 | `list[dict]` | 解码后的事件 |
| `params()` | — | `dict[str, dict]` | `{名字: {"value": float, "default": float\|None}}` |
| `param(name, default=None)` | `name: str` | `float\|None` | 单个参数值；没有就返回 `default` |
| `modes()` | — | `list[dict]` | `[{"t0": float, "t1": float, "mode": "LOITER"}, ...]` |
| `tracks()` | — | `list[dict]` | 全部位置轨迹（主轨迹在第一个），见下 |
| `track(key=None)` | `key: str\|None` | `dict` | 单条轨迹；`None` = 主轨迹 |

`channels()` 每项的键：

```python
{"key": "VIBE#0.VibeX",     # 机器可读唯一键（TYPE#实例.字段）
 "type": "VIBE", "field": "VibeX", "inst": 0,
 "label": "VIBE[0].VibeX",  # 给人看的
 "unit": "m/s²", "count": 12345,
 "t0": 0.0, "t1": 302.4,
 "vmin": -3.2, "vmax": 18.9,   # 多实例报文这里是 nan（用 channel_range 拿准值）
 "coltype": "f"}
```

`series()` 参数语义：

- `t0` / `t1`：秒（自 boot 的相对时间，**不是** UNIX 时间戳）；`None` = 不限。
- `max_points`：超过就等间隔抽稀（保留首末点）。大日志一定要给，别把 100 万点全拉进内存。
- `drop_nan=True`：把值为 nan 的点丢掉；默认保留。
- `key` 写法三种都认：`VIBE#0.VibeX`、`VIBE[0].VibeX`、`VIBE.VibeX`（不写实例 = 最小实例）。

`SeriesData`（frozen dataclass）：

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `key` / `label` / `unit` | `str` | |
| `t` / `v` | `np.ndarray` | `float64`，**不可写**（`flags.writeable == False`） |
| `n` | `int`（属性） | 点数 |
| `finite()` | `np.ndarray` | 有限值掩码 |
| `stats()` | `dict` | `min max mean std rms p05 p50 p95 n`（空序列全 `nan`） |

`EnvelopeData`（frozen）：`key label unit t vmin vmax vmean count`、`n`（桶数）。

`events()` 的入参和返回：

- `kinds`：只看这些事件种类（如 `["MSG","ERR"]`），`None` = 全部。
- `severity_min`：`"info" / "hint" / "warn" / "error" / "critical"` 里挑一个当**下限**。
- 返回 `EventRec.as_dict()`：`t kind code ecode text decoded display severity extra`。

`tracks()` 每项的键：

```python
tr = {"key": "POS", "label": "EKF 位置", "kind": "geodetic",   # 或 "local"
      "n_points": 7736, "distance": 1520.3, "max_speed": 12.4,
      "home": (30.123, 120.456, 12.0),      # 没记 home 就是 None
      "origin": (30.123, 120.456, 12.0),    # 同上
      "src_names": ["POS", "GPS"], "note": "",
      "t": t_arr, "lat": lat_arr, "lon": lon_arr, "alt": alt_arr,
      "e": e_arr, "n": n_arr, "u": u_arr, "speed": spd_arr}   # 数组均不可写
```

> `kind == "local"` 时 `lat/lon` 无效（无 GPS 的日志只有 e/n/u 局部坐标）。

#### 没有打开日志时

| 调用 | 行为 |
| --- | --- |
| `ctx.store.available` | `False` |
| `types() / channels() / keys() / events() / params() / modes() / tracks()` | 返回空容器（`[]` 或 `{}`） |
| `param(name, default)` | 返回 `default` |
| `series() / series_dict() / envelope() / channel_range() / track()` | **抛 `RuntimeError("还没有打开日志：请先打开一份 .BIN")`** |

所以正确写法永远是先判断：

```python
def on_loaded(info):
    if not ctx.store.available:
        return
    s = ctx.store.series("BAT.Volt", max_points=5000)
    ...
```

#### 示例：找出电压最低的时刻

```python
def register(ctx):
    def lowest_voltage(store):
        try:
            s = store.series("BAT.Volt", max_points=20000)
        except (RuntimeError, KeyError):
            return None
        v = s.v
        if v.size == 0 or not (v == v).any():        # 全 nan
            return None
        i = int(v.nanargmin())
        return {"t": float(s.t[i]), "volt": float(v[i]), "unit": s.unit}

    ctx.signals.log_loaded.connect(
        lambda info: ctx.log.info("电压最低点: %s", lowest_voltage(ctx.store)))
```

### 3.2 `ctx.control` —— 主动控制宿主

所有方法都返回 `bool`（成功/受理）或 `None`，**从不抛异常**：宿主内部出错会转成
`pluginError` 信号 + 状态栏一句话，同时返回 `False`。

| 方法 | 参数 | 返回 | 行为 / 何时返回 False |
| --- | --- | --- | --- |
| `open_log(path)` | `path: str` | `bool` | 异步解析并打开；文件不存在 → 状态栏提示 + `False` |
| `seek(t)` | `t: float` | `bool` | 游标/地图/时间线一起定位到第 t 秒；没有日志、或 t 不在当前时间线区间内 → `False` |
| `zoom(t0, t1)` | `t0, t1: float` | `bool` | 曲线放大到区间（自动排序）；没有日志 / 区间非法 → `False` |
| `play(on)` | `on: bool` | `bool` | 开始/停止播放；没有日志 → `False` |
| `set_preset(preset_id)` | `preset_id: str` | `bool` | 切换预设视图；id 不存在 → `False` |
| `add_channel(key)` | `key: str` | `bool` | 把手动通道加进曲线页并切到曲线页；键解析失败 → `False` |
| `select_tab(name)` | `name: str` | `bool` | 按**标签页标题**切换（如 `"轨迹地图"`）；找不到 → `False` |
| `status(text)` | `text: str` | `None` | 状态栏显示 `插件：<text>`（几秒后消失） |
| `refresh()` | — | `bool` | 重算并重画当前视图（预设重新取数，较慢，别每帧调） |
| `export_png(path)` | `path: str` | `bool` | 把当前曲线页导出 PNG |

示例：在自己的标签页上放几个按钮

```python
def register(ctx):
    from PySide6 import QtWidgets

    page = QtWidgets.QWidget()
    lay = QtWidgets.QVBoxLayout(page)
    lay.addWidget(QtWidgets.QLabel("跳转"))

    for label, fn in (("开始处", lambda: ctx.control.seek(0.0)),
                      ("播放", lambda: ctx.control.play(True)),
                      ("看曲线", lambda: ctx.control.select_tab("曲线")),
                      ("震动预设", lambda: ctx.control.set_preset("vibe"))):
        b = QtWidgets.QPushButton(label)
        b.clicked.connect(fn)
        lay.addWidget(b)
    ctx.register_tab("跳转演示", page)
```

### 3.3 `ctx.signals` —— 事件订阅

`ctx.signals` 是一个 `QObject`，所有信号参数都是**纯数据**（dict/list/float/str），不带宿主内部对象。
所有插件共用同一个信号对象，各自 `connect` 即可。

| 信号 | 参数 | 触发时机 | 载荷 |
| --- | --- | --- | --- |
| `log_loaded` | `object`（dict） | 日志加载完成、界面填好、加载遮罩收掉之后 | `{"name","path","stats":{...},"types":[...],"n_alerts":int}`，其中 `stats` 含 `firmware frame_type duration t_start t_end n_messages n_params pos_source mode_seq` |
| `log_closed` | — | 切换到**另一份**日志之前（旧日志即将不可用） | 无 |
| `alerts_updated` | `object`（list） | 日志加载完成时、以及每次告警重算后（改阈值等） | `[AlertHit.as_dict(), ...]`：`rule title severity t0 t1 value threshold unit channel channel_label message evidence source` |
| `time_changed` | `float` | 游标每次移动：点击时间线、拖动、播放中每帧（约 20 fps） | 当前时刻（秒） |
| `play_state` | `bool` | 播放开始 / 停止时**各一次** | `True`=开始播放，`False`=停止 |
| `mode_changed` | `str` | 当前飞行模式**变化**时（同一模式不重复发） | 模式名，如 `"LOITER"` |
| `selection_changed` | `object`（dict） | 曲线框选确定区间时；点「复位视图」回到全段时 | `{"t0","t1","whole_log"}`；回到全段时 `whole_log=True` 且 `t0/t1` 为全程 |
| `settings_changed` | `str, object` | 任意设置项被修改（设置页、曲线页控件、插件都会触发） | `(key, value)`，键名见 `ctx.settings.keys()` |
| `plugins_changed` | `object`（list） | 插件被加载 / 停用 / 启用 / 重载后 | `[PluginInfo.as_dict(), ...]`：`id name version path status error errors provides` |
| `theme_changed` | `str` | 界面主题变化后 | 主题值：`"system"/"light"/"dark"/"custom"/"plugin:<pid>:<id>"` |
| `theme_error` | `str, str` | 主题不可用、已回退内置默认主题时 | `(原主题值, 原因)` |

**顺序（实测）**：换一份日志时依次是 `log_closed` → `alerts_updated` → `log_loaded`；
首次打开没有 `log_closed`，就是 `alerts_updated` → `log_loaded`。
所以“准备数据”放 `log_loaded`，“清缓存”放 `log_closed`，不要在两边都做一遍。

示例：

```python
def register(ctx):
    def on_loaded(info):
        s = info["stats"]
        ctx.log.info("%s：%s %s，时长 %.0fs，告警 %d 条",
                     info["name"], s.get("firmware"), s.get("frame_type"),
                     float(s.get("duration") or 0), info["n_alerts"])

    def on_time(t):
        pass                     # 别在这里做重活：播放时每秒会来 20 次

    ctx.signals.log_loaded.connect(on_loaded)
    ctx.signals.time_changed.connect(on_time)
    ctx.signals.mode_changed.connect(lambda m: ctx.log.info("模式 → %s", m))
```

**线程**：这些信号都在宿主主线程发出。你的槽函数也在主线程执行，可以直接操作 Qt 控件；
反过来，**不要**在工作线程里直接改界面——用 `QtCore.Signal` 抛回主线程。

## 4. 七类挂载点

统一规则：

- 都在 `register(ctx)` 里调用，**返回值是 `bool`**：`False` = 被拒（原因会写进插件页的错误信息）。
- 同一个插件可以注册多个（同名/同 id 的会被拒）。
- 停用插件时，这些注册内容**全部**被摘掉，界面立刻回到没有它的样子。

### 4.1 自定义告警规则 `register_alert_rule(fn)`

```text
ctx.register_alert_rule(fn) -> bool
# fn(store: StoreView) -> dict | list[dict] | None
```

返回的每条告警字典：

| 键 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `title` | `str` | **是**（或用 `rule` 兜底） | 告警标题，显示在告警页/时间线 |
| `severity` | `str` | 否 | `info` / `hint` / `warn` / `error` / `critical`；其它值按 `warn` |
| `t0` / `t1` | `float` | 建议给 | 秒；`t1` 不给就等于 `t0`（瞬时） |
| `value` / `threshold` | `float` | 否 | 触发值与阈值，用于显示 |
| `unit` | `str` | 否 | 单位 |
| `message` | `str` | 否 | 详细说明 |

**会被丢弃的情况**（不会报错，也不会出现在告警页）：

- 元素不是字典；
- `title` 和 `rule` 都是空串；
- 数值字段给的是无法转 float 的东西（会当成 `nan`，不丢整条）。

**注意**：

- 规则是**同步调用**的：加载日志时、改阈值时都会跑。请控制耗时（用 `max_points` 抽稀）。
- 只在**有日志**时才会被调用；没有日志时宿主直接跳过。
- 插件告警排在引擎自己的告警之后；`source` 固定为 `plugin:<你的 id>`，一眼能看出是谁报的。

```python
def register(ctx):
    def rule(store):
        try:
            s = store.series("BAT.Volt", max_points=20000)
        except (RuntimeError, KeyError):
            return []
        if s.n == 0:
            return []
        cells = store.param("BATT_CELLS") or 0
        if not cells:
            return []
        per_cell = s.v / float(cells)
        i = int(per_cell.nanargmin())
        low = float(per_cell[i])
        if low >= 3.35:
            return []
        return [{"rule": "low_cell", "title": "单芯电压偏低",
                 "severity": "warn" if low >= 3.1 else "critical",
                 "t0": float(s.t[i]), "t1": float(s.t[i]),
                 "value": low, "threshold": 3.35, "unit": "V",
                 "message": f"按 {int(cells)}S 折算最低 {low:.3f} V/芯"}]

    ctx.register_alert_rule(rule)
```

### 4.2 虚拟/派生通道 `register_synthetic_channel(key, fn, *, label, unit)`

```text
ctx.register_synthetic_channel(key, fn, label="", unit="") -> bool
# fn(store: StoreView) -> (t, v) | SeriesData | {"t": ..., "v": ...}
```

| 参数 | 说明 |
| --- | --- |
| `key` | **必须**是 `TYPE.field` 形式（`TYPE`/`FIELD` 只允许字母数字下划线，可带 `#n` 实例号），如 `"SYN.KE"`、`"SYN#0.Test"` |
| `fn` | 计算函数，返回 `t`、`v` 两个**等长**序列 |
| `label` | 通道树里显示的名字（默认 `TYPE.FIELD`） |
| `unit` | 单位（默认空） |

**会被拒绝的情况**：

- `key` 不能解析成 `TYPE.field`（例如没有点号、含中文或空格）；
- `fn` 不是可调用对象；
- 这个 `key` 已经被别的插件（或自己）注册过（**先注册先得**）。

**运行时会被丢弃的情况**：返回值的形状不对、`t` 与 `v` 长度不一致、`fn` 抛异常。

注册成功后：通道树顶部出现「插件通道」组，双击即可画到曲线页；插件自己写的预设也能引用它。
`ctx.store` 只描述真实报文字段（见 7.5 已知限制）。

```python
import numpy as np

def register(ctx):
    def kinetic(store):
        try:
            s = store.series("GPS.Spd", max_points=20000)     # m/s
        except (RuntimeError, KeyError):
            return np.empty(0), np.empty(0)
        mass = store.param("PLUGIN_MASS_KG", 1.5) or 1.5
        return s.t, 0.5 * float(mass) * np.asarray(s.v) ** 2

    ctx.register_synthetic_channel("SYN.KE", kinetic, label="动能", unit="J")
```

### 4.3 预设视图 `register_preset(preset)`

```python
from apmlog.plugins import Preset, LaneRequest, LanePair


def register(ctx):
    ctx.register_preset(Preset(id="my_energy", name="我的：动能", lanes=[
        LaneRequest(type="SYN", fields=["KE"]),
        LaneRequest(type="GPS", fields=["Spd"]),
    ], note="动能按 PLUGIN_MASS_KG 计算"))
```

`Preset` 字段：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `id` | — | **必填**，全局唯一；不要用内置 id（`position motor battery vibe attitude gps`） |
| `name` | — | **必填**，下拉里显示的名字（会自动加「（插件）」后缀） |
| `lanes` | `[]` | `LaneRequest` 或 `LanePair` 列表，按顺序成道 |
| `max_points` | `20000` | 每道取数上限 |
| `envelope_above` | `4000` | 点数超过就改用包络 |
| `note` | `""` | 备注（暂不显示在主界面） |

`LaneRequest`：`type`（报文类型或 `TRACK`/`SYN`）、`fields`（字段名列表）、`inst`（实例号，`None`=最小实例）、
`fixed_range`（`(lo, hi)` 固定 Y 轴）、`threshold`（画一条阈值线）、`band`（`(lo, hi)` 画正常带）、
`style`（默认 `"line"`）、`label_prefix`（道名前缀）、`hide`（这些字段初始隐藏）。

`LanePair`：`type`、`primary`（主曲线字段）、`overlays`（同轴叠加的字段，如 `DesRoll`）、
`overlays_hidden`（默认 `True`）、`overlay_labels`，其余同上。

**会被拒绝的情况**：缺 `id`/`name`/`lanes` 属性；`id` 为空；`id` 与另一个插件已注册的预设重复。

> 与内置预设同 id 不会报错，但**不会出现在下拉里**（界面跳过），所以避开那 6 个 id。

### 4.4 曲线右键工具 `register_plot_tool(name, callback)`

```text
ctx.register_plot_tool(name, callback) -> bool
# callback(ctx: PluginContext, selection: PlotSelection) -> str | dict | list | None
```

在曲线任意一道上右键，菜单底部会多出「`name`…」。点击后回调收到：

| `PlotSelection` 字段 | 类型 | 说明 |
| --- | --- | --- |
| `lane_index` | `int` | 第几条道（0 开始） |
| `lane_label` | `str` | 道名 |
| `keys` | `tuple[str, ...]` | 这道里的通道键（主曲线 + 叠加曲线） |
| `t0` / `t1` | `float` | 有框选就是选区；没框选就是当前视图区间 |
| `whole` | `bool` | `True` = 没有选区（`t0/t1` 只是当前视图，不代表全程） |
| `duration()` | `float` | `t1 - t0` |

**返回值**：字符串 → 弹窗显示；其它非 `None` → 转成文本弹窗；`None` → 什么都不显示。
**会被拒绝**：名称空、回调不可调用。**运行期异常**：只记一次错误，不弹窗、不影响别的功能。

```python
def register(ctx):
    def stats_tool(inner_ctx, sel):
        lines = [f"区间 {sel.t0:.1f}–{sel.t1:.1f}s（{'当前视图' if sel.whole else '选区'}）"]
        for key in sel.keys:
            try:
                s = inner_ctx.store.series(key, sel.t0, sel.t1, max_points=20000)
            except (RuntimeError, KeyError):
                lines.append(f"  {key}: 取不到")
                continue
            st = s.stats()
            lines.append(f"  {key}: 均值 {st['mean']:.3f}{s.unit} 峰值 {st['max']:.3f}{s.unit}")
        return "\n".join(lines)

    ctx.register_plot_tool("统计选中区间", stats_tool)
```

### 4.5 地图自定义图层 `register_map_layer(layer)`

```text
ctx.register_map_layer(layer) -> bool     # layer 有 render(store) 即可（可继承 MapLayerPlugin）
```

图层对象的属性：

| 属性 | 默认 | 说明 |
| --- | --- | --- |
| `name` | `"插件图层"` | 图层名（插件页/排查用） |
| `color` | `"#2f6fed"` | 默认颜色；图元自带颜色时以图元为准 |
| `visible` | `True` | 设 `False` 则不渲染（每次重画都会检查） |
| `render(store)` | — | **必须实现**，返回图元列表 |

`render()` 返回的图元（三种，可混用）：

```python
{"kind": "line",   "points": [(lat, lon), ...], "color": "#ff8800", "width": 2, "dash": False}
{"kind": "point",  "lat": 30.0, "lon": 120.0, "label": "home", "color": "#e74c3c"}
{"kind": "circle", "lat": 30.0, "lon": 120.0, "radius_m": 30.0, "color": "#f0a500"}
```

校验规则（超出的**静默丢弃那一个图元**，不猜位置）：

| 字段 | 合法值 | 越界处理 |
| --- | --- | --- |
| `points` | 至少 2 个 `(lat, lon)`，`-90≤lat≤90`、`-180≤lon≤180`，必须有限 | 有一个点非法 → **整条线不画** |
| `width` | 1–12（整数） | 夹到边界 |
| `label` | 字符串 | 截断到 40 字符 |
| `radius_m` | `> 0` 且 `≤ 100000` | 丢弃该圆 |
| `color` | `#rgb` / `#rrggbb` | 退回图层默认色 |
| 数量 | 单层 ≤ 400 图元、单线 ≤ 5000 点、总量 ≤ 50 层 | 超出部分丢弃 |

坐标一律是 **WGS-84 经纬度**；高德瓦片源下宿主负责 GCJ-02 纠偏，你不用管。

```python
def register(ctx):
    class HomeLayer:
        name = "起飞点"
        color = "#ffb400"

        def render(self, store):
            tracks = store.tracks()
            if not tracks:
                return []
            tr = tracks[0]
            home = tr.get("home")
            if home:
                lat, lon = float(home[0]), float(home[1])
            else:
                lats, lons = tr.get("lat"), tr.get("lon")
                if lats is None or len(lats) == 0:
                    return []                      # 没有地理坐标就不画（不自造位置）
                lat, lon = float(lats[0]), float(lons[0])
            return [{"kind": "point", "lat": lat, "lon": lon, "label": "home"},
                    {"kind": "circle", "lat": lat, "lon": lon, "radius_m": 30.0}]

    ctx.register_map_layer(HomeLayer())
```

### 4.6 独立标签页 `register_tab(title, widget)`

```text
ctx.register_tab(title, widget) -> bool
```

- `widget` **必须**是 `QWidget` 实例（不是类、不是字符串）。
- `title` 不能为空；会追加到主窗标签栏**最右侧**。
- 停用插件 → 该页被移除；重新启用 → 再加回来。
- 页面里的控件可以直接用 `ctx.control` 操作宿主。

**会被拒绝**：`widget` 不是 `QWidget`；标题为空。

```python
def register(ctx):
```

### 4.7 导出器 `register_exporter(name, fn)`

```text
ctx.register_exporter(name, fn) -> bool
# fn(store: StoreView, path: str) -> str | None
```

- 用户路径：插件页 →「插件导出器」→ 选中 →「运行…」→ 选保存位置。
- **两种写法**：
  - 自己写文件（`Path(path).write_text(...)`），返回值给 `None`；
  - 直接 `return` 一个字符串，宿主负责以 UTF-8 写进 `path`。
- **算失败的情况**：回调抛异常；返回字符串但写文件失败；调用结束后 `path` 不存在（说明你既没写也没返回）。
- 没有打开日志时不会调用，直接提示「还没有打开日志」。

```python
def register(ctx):
    def summary(store, path):
        s = store.stats()
        lines = [f"日志 {store.name()}",
                 f"固件 {s.get('firmware')}｜机型 {s.get('frame_type')}",
                 f"时长 {float(s.get('duration') or 0):.1f} s｜报文 {s.get('n_messages')}"]
        for m in store.modes():
            lines.append(f"  模式 {m['mode']} {m['t0']:.1f}–{m['t1']:.1f}s")
        return "\n".join(lines)          # 宿主负责写文件

    ctx.register_exporter("航段摘要", summary)
```

## 5. 主题插件

### 5.1 `ThemeSpec`

```python
from apmlog.plugins import ThemeSpec

ThemeSpec(id="midnight", name="午夜蓝", colors={
    "window": "#131a26", "base": "#0d1320", "text": "#e4ecff", "accent": "#4d9dff",
}, curve="")      # curve 可省
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `str` | `[0-9A-Za-z_.-]{1,40}`，**同一插件内**唯一（不同插件可以同名） |
| `name` | `str` | 显示名，非空 |
| `colors` | `Mapping[str, str]` | **四个角色必须全给**（见下） |
| `curve` | `str` | `""`（按底色亮度自动选亮线/暗线）、`"light"`、`"dark"` |

四个颜色角色（也接受设置项写法 `c_window` 等）：

| 角色 | 影响 |
| --- | --- |
| `window` | 窗口、工具条、表格/树的底 |
| `base` | 列表、输入框、时间线的底 |
| `text` | 正文文字 |
| `accent` | 选中行、游标、按钮高亮 |

**颜色格式**：只接受 `#rgb` 或 `#rrggbb`（大小写都行）。`red`、`rgb(1,2,3)`、`#12345`、
`#gggggg` 一律**拒绝注册**——不会自动纠正，也不会半套生效。

**可读性建议**：`text` 与 `window`/`base` 的 WCAG 对比度最好 ≥ 4.5（宿主只会按你的颜色刷 palette，
不会替你把文字调亮）。深浅两套主题各挑一个极端值最容易踩雷，写完用眼睛在实机上过一遍。

### 5.2 注册、查询、应用

```text
ctx.register_theme(ThemeSpec(...)) -> bool   # 注册（校验见上）
ctx.themes() -> list[dict]                   # 全部已注册主题（含别人的）
ctx.apply_theme("midnight") -> bool          # 自己的主题 id
ctx.apply_theme("plugin:other:pink") -> bool # 别的插件的主题（完整值）
ctx.apply_theme("dark") -> bool              # 内置：system/light/dark/custom
```

`ctx.themes()` 每项：`{"id","name","curve","colors"}`（**不含**归属插件，是给本插件看自己注册了什么用的）。
给界面用的 `value` 形式见下。

**三个入口都能选主题**：

1. 设置 → 界面主题：内置四项后接分隔线，再接「插件：午夜蓝」若干项（选中即生效并写入设置）；
2. 插件页 → 插件主题：列出全部插件主题（`●` 标当前生效），「应用主题」按钮切换；
3. 插件自己调 `ctx.apply_theme(...)`。

### 5.3 主题 id 存在哪里

设置项 `ui_theme` 的值形如：

```
system | light | dark | custom | plugin:<插件 id>:<主题 id>
```

例：`plugin:theme_plugin:midnight`。用完整值是为了「插件停用/删掉后还能看出属于谁」。
你也可以读 `ctx.settings.get("ui_theme")` 判断当前是不是自己的主题。

### 5.4 失效回退（宿主行为）

| 情况 | 宿主怎么做 |
| --- | --- |
| 注册时颜色缺失/非法、id 非法、id 重复、`curve` 非法 | 只拒这一套主题 + 记错误；若该插件**只提供主题且全部被拒**，整插件判「加载失败」 |
| 设置里存着 `plugin:x:y`，但插件没加载/被停用/被删了 | 回退内置默认主题（`system`）+ 状态栏提示 |
| 应用时主题数据坏掉（例如你运行期把 colors 改坏了） | 回退默认 + 日志 + **停用该插件**（只停它） |
| 应用过程中宿主抛异常 | 同上 |
| 用户在你的主题生效时点「停用插件」 | 立刻回退默认主题 |

回退动作固定：`ui_theme` 改回 `system` → palette 刷回内置 → 状态栏一句话 →
`theme_error` 信号 → `theme_changed("system")`。**不会重启、不会清你的设置文件、不影响其它插件。**

主题生效期间如果你需要知道"自己被换下了"，连 `theme_changed` 看值是不是自己的即可。

### 5.5 完整示例

```python
PLUGIN_NAME = "示例：两套配色"
__version__ = "1.0"
```

## 6. 生命周期与容错

### 6.1 出错了会怎样

| 阶段 | 出错后 | 用户看到 |
| --- | --- | --- |
| import（模块顶层） | 插件「加载失败」，模块从 `sys.modules` 移除 | 插件页状态红字 `加载失败`，「查看错误…」有 traceback；状态栏一句「插件 x：加载失败：…」 |
| `register()` 里 | 同上；**已经注册的内容全部撤掉** | 同上 |
| 少了 `register` | 「加载失败：插件缺少 register(ctx) 入口」 | 同上 |
| 运行期回调（告警规则/工具/图层/导出器/主题应用/信号槽） | 记 1 次错误，本次调用当作"没有结果" | 状态栏一句；错误次数与 traceback 记在插件页 |
| 累计 5 次运行期异常 | 自动「已停用」并摘掉全部内容 | 插件页状态 `已停用`，错误信息写明"连续 N 次异常，已自动停用" |

**"隔离"到什么程度**：你的异常**不会**冒到 Qt 事件循环、不会让主窗崩、不会影响其它插件。
但也只是"异常隔离"——不是安全沙箱（见 7.2）。

### 6.2 插件之间互不影响

- 每个插件的注册内容都带 owner（插件 id），停用一个不会动到别人的。
- 同一个挂载点被多个插件注册：**按注册顺序**生效（告警规则、地图图层、导出器列表都是）。
- 全局唯一的几个键要先到先得：合成通道 `key`、预设 `id`（插件之间）、主题 `(插件, 主题 id)`。
  被占用时会**拒绝**后来者并记错误，不会静默覆盖。

### 6.3 错误信息在哪看

1. 插件页 → 选中行 →「查看错误…」（完整 traceback + 最近一次错误摘要）；
2. 状态栏（一句话，几秒后消失）；
3. 源码运行时：控制台 `logging` 输出（logger 名 `apmlog.plugin.<id>`）。

## 7. 能力边界（先看这段，能省很多试错）

### 7.1 执行在哪

- **同一个进程、同一个主线程**：`register()` 和所有回调都在宿主主线程执行，可以直接操作 Qt 控件。
- **没有超时强杀**：宿主不会因为你卡住就把你杀掉，只会让界面卡住（用户会看到"程序没反应"）。
  重活请自己开 `QThread`/`threading.Thread`，算完用 `QtCore.Signal` 把结果送回主线程再动界面。
- **不要在回调里做这些**：`QApplication.quit()`、`app.exec()`、递归调用 `ctx.control.refresh()`、
  在自己停用过程中再注册内容。

### 7.2 隔离级别

| 项 | 是否保证 |
| --- | --- |
| 插件异常不影响宿主和其它插件 | ✅ 保证（全部经过沙箱守卫） |
| 插件**改不动**宿主数据（`ctx.store` 只读、`ctx.settings` 只读） | ✅ 保证 |
| 插件**看不到**宿主的文件/网络 | ❌ 不保证：它就是普通 Python 代码，能 import `os`、`socket`，能读写文件 |
| 插件内存/CPU 限额 | ❌ 没有 |
| 插件崩溃（段错误）隔离 | ❌ 没有：同进程，C 层崩溃会带走整个程序 |

一句话：**信任模型是"用户自己放进去的代码"**。写插件时请像写自己程序的一部分那样自律。

### 7.3 性能建议

- 取数一定给 `max_points`（20000 是个好默认）；整段几百万点的通道会吃掉几百 MB。
- `time_changed` 在播放时每秒约 20 次：回调里只做 O(1) 的事（比如更新一个 label）。
- 告警规则在每次加载/改阈值时都会跑：用 `max_points` + 早退（数据不够就直接 `return []`）。
- `map_layer.render()` 在每次加载/插件变更时调用：别在里面做重计算，缓存到 `self` 上。
- 需要重复读同一段数据时，自己按 `(日志名, 通道)` 做一层缓存，并在 `log_loaded` 里清掉。

### 7.4 已知限制（当前的，别踩空）

1. **`ctx.store` 只反映真实报文字段**：别的插件注册的合成通道（`SYN.*`）不在 `ctx.store.channels()`
   里，`ctx.store.series("SYN.X")` 会 `KeyError`。需要同类数据就自己算一遍。
   （合成通道只在宿主界面里可见：通道树、预设、图表。）
2. **`register_tab` 的页面停用后会被移除**：不要在页面里存"唯一一份"的状态，重新启用时会被重新构造。
3. **主题只能改四色**：不能换控件绘制、不能注册 QSS、不能只给某个标签页换色。
4. **导出器只能由用户在插件页手动触发**：没有"保存时自动导出"钩子。
5. **插件设置不存在宿主设置里**：宿主只读（`ctx.settings` 只读），你自己的配置请写到自己的文件
   （建议 `%LOCALAPPDATA%\APMLogViewer\` 下自建子目录）。

| 你会做错的事 | 结果 |
| --- | --- |

### 8.3 常见问题

**Q：插件页里没有我的插件。**
A：① 文件名是不是 `.py`？② 是不是以 `_`/`.` 开头？③ 目录是不是加对了（插件页「插件目录」列表能看到）？
④ 点过「重新扫描并重载」没有？

**Q：显示「加载失败」，但我不觉得有错。**
A：选中那行点「查看错误…」。最常见的是 import 了绿色包里没有的库（例如 `scipy`），
或者 `register` 里写了 `NameError`/缩进错误。

**Q：标签页出现了，但一打开日志就报错。**
A：大概率是在 `register` 阶段读了 `ctx.store`（那时还没日志）。改成在 `log_loaded` 回调里读。

**Q：合成通道注册了，通道树里却没有。**
A：注册被拒了（key 不合法/重复）。通道树「插件通道」组只在**至少有一个**合成通道时出现；
另外它只在**打开日志之后**显示，因为点数要现算。

**Q：我的告警规则没触发。**
A：先确认 `_compute_alerts` 那条链路：① 规则函数返回的是 list 不是 `None`；② 每条有 `title`；
③ 没有日志时规则不会被调用；④ 你的插件是不是已经被自动停用（插件页看状态）。

**Q：改完插件代码，重载后行为没变。**
A：「重新扫描并重载」会重新 import，但如果你在模块顶层缓存了东西（比如常量表），
需要保证重启宿主或改用「停用 → 启用」。最稳的是关掉宿主重开。

**Q：绿色包里 `import scipy` 失败。**
A：绿色包只带内置清单里的库。让打包的人 `pip install scipy` 后重新 build；
或者插件自己用 numpy 实现。

**Q：插件能写文件吗？**
A：能（普通 Python 代码）。但请只写自己的目录（建议 `%LOCALAPPDATA%\APMLogViewer\` 下自建子目录），
不要改日志、不要改宿主设置文件。

**Q：怎么知道自己是被"停用"了？**
A：连 `ctx.signals.plugins_changed`，在列表里找自己的 id 看 `status`；或者连 `theme_error`
（主题相关时）。

### 8.4 完整示例：七件套

下面这份可以直接存成 `example_plugin.py` 放进插件目录（与仓库里 `plugins-samples/example_plugin.py` 同源）：

```python
PLUGIN_NAME = "示例：动能与航段摘要"
__version__ = "1.0"

import numpy as np
from PySide6 import QtWidgets
from apmlog.plugins import LaneRequest, Preset


def register(ctx) -> None:
    log = ctx.log

    # 1) 虚拟通道：动能 ½·m·v²
    def kinetic(store):
        try:
            s = store.series("GPS.Spd", max_points=20000)
        except (RuntimeError, KeyError):
            return np.empty(0), np.empty(0)
        mass = store.param("PLUGIN_MASS_KG", 1.5) or 1.5
        return s.t, 0.5 * float(mass) * np.asarray(s.v) ** 2

    ctx.register_synthetic_channel("SYN.KE", kinetic, label="动能", unit="J")

    # 2) 预设视图
    ctx.register_preset(Preset("demo_energy", "插件：动能与速度",
                               [LaneRequest("SYN", ["KE"]), LaneRequest("GPS", ["Spd"])],
                               note="动能按 PLUGIN_MASS_KG 计算（缺省 1.5 kg）"))

    # 3) 告警规则（注意：ctx.store 只映射真实报文，读自己的 SYN.KE 会 KeyError，
    #    所以这里直接用同一个公式算一遍）
    def energy_rule(store):
        try:
            s = store.series("GPS.Spd", max_points=20000)
        except (RuntimeError, KeyError):
            return []
        mass = store.param("PLUGIN_MASS_KG", 1.5) or 1.5
        v = 0.5 * float(mass) * np.asarray(s.v) ** 2
        if v.size == 0:
            return []
        i = int(np.nanargmax(v))
        if float(v[i]) < 5000.0:
            return []
        return [{"rule": "ke_high", "title": "动能偏高", "severity": "warn",
                 "t0": float(s.t[i]), "t1": float(s.t[i]), "value": float(v[i]),
                 "threshold": 5000.0, "unit": "J",
                 "message": "插件规则：½mv² 峰值超过 5000 J"}]

    ctx.register_alert_rule(energy_rule)

    # 4) 曲线右键工具
    def stats_tool(inner_ctx, sel):
        lines = [f"区间 {sel.t0:.1f}–{sel.t1:.1f}s（{'整段' if sel.whole else '选区'}）"]
        for key in sel.keys:
            try:
                s = inner_ctx.store.series(key, sel.t0, sel.t1)
            except (RuntimeError, KeyError):
                lines.append(f"  {key}: 取不到")
                continue
            st = s.stats()
            lines.append(f"  {key}: 均值 {st['mean']:.3f}{s.unit} 峰值 {st['max']:.3f}{s.unit}")
        return "\n".join(lines)

    ctx.register_plot_tool("统计选中区间", stats_tool)

    # 5) 地图图层
    class HomeLayer:
        name = "示例：home 圈"
        color = "#ffb400"

        def render(self, store):
            tracks = store.tracks()
            if not tracks:
                return []
            tr = tracks[0]
            home = tr.get("home")
            if home:
                lat, lon = float(home[0]), float(home[1])
            else:
                lats, lons = tr.get("lat"), tr.get("lon")
                if lats is None or len(lats) == 0:
                    return []
                lat, lon = float(lats[0]), float(lons[0])
            return [{"kind": "point", "lat": lat, "lon": lon, "label": "home"},
                    {"kind": "circle", "lat": lat, "lon": lon, "radius_m": 30.0}]

    ctx.register_map_layer(HomeLayer())

    # 6) 导出器
    def summary_export(store, path):
        s = store.stats()
        lines = [f"日志 {store.name()}",
                 f"固件 {s.get('firmware')}｜机型 {s.get('frame_type')}",
                 f"时长 {float(s.get('duration') or 0):.1f} s｜报文 {s.get('n_messages')}"]
        lines += [f"  模式 {m['mode']} {m['t0']:.1f}–{m['t1']:.1f}s" for m in store.modes()]
        return "\n".join(lines)

    ctx.register_exporter("航段摘要", summary_export)

    # 7) 独立标签页 + 事件订阅
    page = QtWidgets.QWidget()
    lay = QtWidgets.QVBoxLayout(page)
    lay.addWidget(QtWidgets.QLabel(f"宿主 {ctx.host_version}，接口 v{ctx.api_version}"))

    def on_loaded(info):
        lay.addWidget(QtWidgets.QLabel(f"已加载 {info.get('name')}"))
        log.info("已加载 %s", info.get("name"))

    ctx.signals.log_loaded.connect(on_loaded)
    ctx.register_tab("示例插件", page)
```
